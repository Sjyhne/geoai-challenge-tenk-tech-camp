GIRL TECH FEST – LAG DITT EGET KART

En kartoppgave for elever i 5. klasse, laget med Kartverket.
1. Finn et sted på flyfotoet.
2. Tegn hus, vei, skog og vann. Du kan også legge til egne typer.
3. Se kartet ditt. Trykk på hver tegning for å se den nærmere.

Tegninger, farger og tekst lagres i nettleseren på denne maskinen.
Start på nytt sletter den nye oppgavens lagrede kart.
Tidligere oppgavers lagring brukes ikke av denne versjonen.

Start med startskriptet for Windows, Mac eller Linux. Python 3 må være installert.
La servervinduet stå åpent mens oppgaven brukes. Ctrl+C stopper serveren.
Du kan også kjøre: python3 -m http.server 8765 --bind 127.0.0.1
Åpne deretter http://127.0.0.1:8765/

Nettstedet kan publiseres direkte som statiske filer, for eksempel med GitHub Pages.
Flyfoto, kartbibliotek og stedsøk krever internett.
